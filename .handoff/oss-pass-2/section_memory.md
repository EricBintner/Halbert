#### Theme 3 — Store durability and recovery: WAL-reset gate, verified backup, salvage, one durable-write helper

That makes a verified backup and a last-resort salvage more important, not less; today there is neither, and the runtime SQLite is in a known-corrupting version band. These are new mechanisms (not in either 09-07 review) and the audit's A08 lost-unit gaps strengthen every one of them.
