## 8. UX rationale

User-facing surface is minimal and must stay that way — this unit wires internals, and the only surface it produces is first-person, grounded, and honest about what the machine did. When a turn was cut before a token streamed (A16-G5), the persisted interrupted marker means the next history no longer shows two bare consecutive user rows — so the machine does not re-stage an already-answered request, and when it surfaces the interruption it speaks as itself ("I was cut off while …"), never as an assistant and never naming a model. When a subject is returned to, the receipt carries the unresolved request forward deterministically (A16-G2) rather than the machine asking again what it was already told. Branch dividers minted by move_leaf are the machine leaving two honest sentences about a topic switch — no emoji, no conversation list, consistent with the one-seamless-conversation directive (the threads are hidden, recall is by relevance). A merge that finds a split was spurious hides the now-false divider rather than deleting it, per the standing directive that superseded rows stay on disk. Colors, if any divider or marker is ever rendered in the dashboard, come only from shared-tokens/tokens.css and pass scripts/check_contrast.py. The rotation itself is invisible to the user by design — recent turns are preserved verbatim and rotated turns stay searchable (test_a_rotated_thread_is_still_searchable); the only user-visible tuning is the rotation threshold ruling, which is precisely why it goes to the founder rather than being chosen in code. Commands staged from this surface remain staged, never executed.
